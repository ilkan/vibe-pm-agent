# Executive Communications Guide - Professional Document Generation

## 📋 Overview

The Vibe PM Agent generates executive-ready communications that meet Fortune 500 standards using proven consulting frameworks. This guide covers document types, formatting standards, and best practices for stakeholder engagement.

## 🎯 Document Types & Frameworks

### Executive One-Pagers
**Purpose:** Board-level decision making with key metrics and recommendations  
**Framework:** Pyramid Principle (conclusion first, supporting details follow)  
**Audience:** C-level executives, board members, senior stakeholders  
**Length:** Exactly 1 page with executive summary format

### PR-FAQ Documents  
**Purpose:** Product announcements using Amazon Working Backwards methodology  
**Framework:** Customer-focused narrative with internal FAQ  
**Audience:** Product teams, marketing, external communications  
**Length:** 2-4 pages with press release + detailed FAQ

### Board Presentations
**Purpose:** Strategic context with financial projections for board approval  
**Framework:** McKinsey-style slide structure with appendix  
**Audience:** Board of directors, investors, senior leadership  
**Length:** 10-15 slides with detailed appendix

### Team Announcements
**Purpose:** Internal communication with technical context and roadmap  
**Framework:** Engineering-focused with implementation details  
**Audience:** Development teams, product managers, technical leads  
**Length:** 1-2 pages with technical specifications

## 📊 Pyramid Principle Framework

### Structure Overview
```
Key Message (What should they do?)
    ↓
Supporting Arguments (Why should they do it?)
    ↓
Evidence and Data (How do we know?)
    ↓
Detailed Analysis (Supporting information)
```

## 🚀 Amazon Working Backwards (PR-FAQ)

### PR-FAQ Structure
```
Press Release (Customer perspective)
    ↓
Frequently Asked Questions (Internal perspective)
    ↓

    ↓

```

## 📈 Board Presentation Framework

### Slide Structure (McKinsey Style)
1. **Executive Summary** - Key recommendation and rationale
2. **Market Opportunity** - TAM/SAM/SOM with competitive landscape
3. **Solution Overview** - Product/service description and differentiation
4. **Financial Projections** - Multi-scenario modeling with assumptions
5. **Strategic Alignment** - Company OKR alignment and portfolio fit
6. **Implementation Plan** - Timeline, resources, and milestones
7. **Risk Assessment** - Key risks with mitigation strategies
8. **Investment Request** - Funding requirements and expected returns
9. **Success Metrics** - KPIs and measurement framework
10. **Next Steps** - Immediate actions and decision requirements

### Slide Content Guidelines
**Title Slide Standards**
- Clear, action-oriented headlines
- Key metric or recommendation in subtitle
- Date and confidentiality marking

**Content Slide Structure**
- One key message per slide
- Maximum 6 bullet points
- Supporting data in charts/tables
- Source citations at bottom

**Visual Design Principles**
- Consistent color scheme and fonts
- High contrast for readability
- Professional charts and graphics
- Minimal text with clear hierarchy

## 💼 Consulting Communication Standards

### MECE Principle Application
**Mutually Exclusive, Collectively Exhaustive**
- No overlap between categories or recommendations
- Complete coverage of all relevant aspects
- Clear logical structure and flow
- Balanced depth across sections

### Pyramid Principle Implementation
**Start with the Answer**
```
Recommendation: Proceed with AI Code Review Assistant investment

Why? Three strategic reasons:
1. Large market opportunity ($2.1B TAM, 23% CAGR)
2. Strong competitive position (12-18 month window)
3. Excellent strategic fit (92% OKR alignment)

Supporting Evidence:
- Market analysis: Gartner, Forrester, McKinsey research
- Competitive intelligence: Feature comparison matrix
- Financial modeling: 300% ROI in balanced scenario
- Strategic assessment: Direct contribution to 3 company OKRs
```

### So What? Test
**Every Statement Must Pass:**
- So what does this mean for the business?
- So what should we do about it?
- So what are the implications if we don't act?

## 🏆 Best Practices Summary

### Content Development
1. **Start with the recommendation** - Lead with what stakeholders should do
2. **Support with evidence** - Use professional citations and quantified benefits
3. **Address concerns proactively** - Include risk assessment and mitigation
4. **Provide clear next steps** - Specific actions with owners and timelines
5. **Maintain professional standards** - Consulting-grade formatting and language

### Stakeholder Engagement
1. **Know your audience** - Adapt content and style to stakeholder needs
2. **Focus on business impact** - Emphasize strategic value and competitive advantage
3. **Quantify everything** - Use specific metrics and financial projections
4. **Be concise and actionable** - Respect executive time with clear, focused content
5. **Follow up systematically** - Track decisions and implementation progress

### Quality Assurance
1. **Peer review process** - Have colleagues review for clarity and completeness
2. **Stakeholder validation** - Test key messages with target audience representatives
3. **Iterative improvement** - Refine based on feedback and outcomes
4. **Template standardization** - Use consistent formats for efficiency and quality
5. **Metrics tracking** - Monitor communication effectiveness and stakeholder satisfaction
