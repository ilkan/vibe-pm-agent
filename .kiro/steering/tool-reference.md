# Vibe PM Agent - Tool Reference Guide

## 🚀 Quick Start - All 27 Tools Ready

### Business Strategy Tools

#### analyze_business_opportunity
**Purpose**: Comprehensive market opportunity analysis
**Input**: Business idea, market context, analysis depth
**Output**: Market assessment, competitive analysis, ROI projections
**Example**: "Analyze the market opportunity for an AI-powered customer service chatbot"

#### assess_strategic_alignment  
**Purpose**: Evaluate feature alignment with company strategy
**Input**: Feature concept, company context (mission, OKRs, priorities)
**Output**: Strategic alignment score, recommendations, risk assessment
**Example**: Strategic alignment for "AI-powered analytics dashboard"

#### validate_market_timing
**Purpose**: Validate if now is the right time to build a feature
**Input**: Feature idea, market signals (competition, demand, readiness)
**Output**: Timing score, market window analysis, implementation timeline
**Example**: Timing validation for "Voice-activated project management tool"

#### optimize_resource_allocation
**Purpose**: Optimize team resources and development efficiency
**Input**: Current workflow, resource constraints, optimization goals
**Output**: Resource optimization plan, cost savings, efficiency gains
**Example**: Optimize development team allocation for faster delivery

#### monitor_market_conditions
**Purpose**: Monitor real-time market conditions and trends
**Input**: Industry, region, monitoring configuration
**Output**: Market trends, competitive intelligence, actionable insights
**Example**: Monitor fintech market conditions for new opportunities

### Document Generation Tools

#### generate_business_case
**Purpose**: Create comprehensive business cases with ROI analysis
**Input**: Opportunity analysis, financial inputs, Amazon mode option
**Output**: Executive-ready business case with financial projections
**Example**: Business case for $750K investment with $1.5M expected revenue

#### create_stakeholder_communication
**Purpose**: Generate stakeholder communications (one-pagers, PR-FAQs)
**Input**: Business case, communication type, target audience
**Output**: Tailored communication for executives, board, or teams
**Example**: Executive one-pager for board presentation

#### generate_management_onepager
**Purpose**: Create executive one-page summaries
**Input**: Requirements, design, tasks, ROI inputs
**Output**: Executive summary with key metrics and recommendations
**Example**: One-pager for new product launch decision

#### generate_pr_faq
**Purpose**: Generate Amazon Working Backwards PR-FAQ
**Input**: Requirements, design, target launch date
**Output**: Press release and FAQ in Amazon format
**Example**: PR-FAQ for new AI platform launch

### Product Development Tools

#### generate_requirements
**Purpose**: Generate business requirements with MoSCoW prioritization
**Input**: Raw intent, context, steering options
**Output**: Structured requirements with priorities and timing
**Example**: Requirements for "real-time collaboration platform"

#### generate_design_options
**Purpose**: Create multiple design approaches with impact analysis
**Input**: Requirements document, steering options
**Output**: Conservative/Balanced/Bold design options with trade-offs
**Example**: Design options for mobile app architecture

#### generate_task_plan
**Purpose**: Create implementation task plans with effort estimation
**Input**: Design document, project limits, steering options
**Output**: Phased task plan with effort estimates and priorities
**Example**: Task plan for 6-month development project

### AWS Integration Tools

#### aws_docs_search
**Purpose**: Search AWS documentation
**Input**: Search query, result limit
**Output**: Relevant AWS documentation pages with summaries
**Example**: Search for "Lambda function configuration"

#### aws_docs_read
**Purpose**: Read specific AWS documentation pages
**Input**: AWS documentation URL, content length, start index
**Output**: Formatted AWS documentation content
**Example**: Read Lambda developer guide

#### aws_docs_recommend
**Purpose**: Get AWS documentation recommendations
**Input**: AWS documentation URL
**Output**: Related documentation recommendations
**Example**: Find related Lambda documentation

#### aws_contextual_info
**Purpose**: Get contextual AWS service information
**Input**: AWS service name, context type, detail level
**Output**: Service information, use cases, best practices
**Example**: Get Lambda use cases and pricing

#### aws_code_generator
**Purpose**: Generate AWS SDK code snippets
**Input**: AWS service, operation, programming language, parameters
**Output**: Ready-to-use AWS SDK code
**Example**: Generate Lambda function deployment code

#### aws_best_practices
**Purpose**: Get AWS best practices recommendations
**Input**: AWS service, use case, compliance requirements
**Output**: Best practices, security recommendations, optimization tips
**Example**: Lambda security best practices
