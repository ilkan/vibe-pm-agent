## 💡 **Usage Examples**

### **Start Interview Preparation**
```json
{
  "tool": "start_interview_preparation",
  "args": {
    "role_level": "Senior PM",
    "target_company": "Google", 
    "preparation_timeline": "3 weeks",
    "focus_areas": ["product_sense", "leadership"]
  }
}
```

### **Generate Practice Question**
```json
{
  "tool": "generate_interview_question",
  "args": {
    "role_level": "PM",
    "question_category": "analytical",
    "company_context": "Meta",
    "difficulty_level": 4
  }
}
```

### **Evaluate Response**
```json
{
  "tool": "evaluate_interview_response", 
  "args": {
    "question_id": "q_123",
    "user_response": "I would use the RICE framework...",
    "evaluation_focus": ["frameworks", "structure"]
  }
}
```
